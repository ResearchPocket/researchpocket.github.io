# ResearchPocket 2.3.0

ResearchPocket 2.3.0 gives the terminal a documents workspace, lets a trusted
browser remember its library token, keeps captured pages apart from excerpts,
and simplifies the Sync view.

## Install

With Rust installed:

```sh
cargo install --locked --force research
```

Or download the verified archive for Linux, macOS, or Windows from the GitHub
release and check it against `SHA256SUMS`.

## What changed

- **The TUI has a documents workspace.** Tab moves between saves and Zen
  documents. The index reads no document bodies; Enter opens one, Space ticks
  the task on the cursor line, and Ctrl+G edits the body in your editor.
  Item mentions resolve against the local library while a document is open.
- **Whole-body document edits refuse stale buffers.** An editor or form opened
  before a concurrent edit landed can no longer silently undo it. A rejected
  buffer is kept in a temporary file whose path is reported.
- **Trusted browsers can remember a library token.** The owner app offers an
  off-by-default **Remember token in this browser** option that reconnects
  after a tab or browser restart. **Forget token**, invalid credentials, and
  profile deletion clear it across tabs. ADR 0013 records the policy change.
- **Captured pages stay out of the excerpt.** Firecrawl enrichment writes the
  whole page only to the item's captured document. The excerpt takes the
  page's own description, or a bounded lead of its Markdown when it has none,
  so large pages no longer replicate through every device and checkpoint.
  `--replace-excerpt` now writes that bounded description too.
- **Captured pages can be dropped.** `research enrich forget <ITEM_ID>` removes
  an item's captured page and keeps the save, excerpt, note, and tags.
- **The Reader shows your excerpt first.** A captured page appears in its own
  collapsible **Captured page** section with its provider, date, and size, and
  loads only when opened. The TUI detail view names the capture as well.
- **Sync is quieter, and there is a new theme.** The Sync view uses one status
  line, one-row pending changes, and collapsed connection settings. Kanagawa
  Wave joins the theme presets, and the sidebar uses consistent icons.
- **Dependencies are updated to clear the security audit**, including rustls,
  quinn-proto, chacha20, and postcss.

Saves enriched with `--replace-excerpt` before this release keep their
whole-page excerpts until they are enriched again:

```sh
research enrich run <item-id> --provider firecrawl --replace-excerpt
```

This release does not change the synchronization protocol, SQLite schema,
operation-pack format, checkpoint format, aggregate generation, or repository
layout. Existing native and hosted clients remain wire-compatible.

## GitHub release archives

| Platform | Release asset |
| --- | --- |
| Linux GNU/glibc x86-64 (glibc 2.35 or newer) | `research-v2.3.0-linux-amd64.tar.gz` |
| Windows x86-64 | `research-v2.3.0-windows-amd64.zip` |
| macOS Intel | `research-v2.3.0-macos-amd64.tar.gz` |
| macOS Apple Silicon | `research-v2.3.0-macos-arm64.tar.gz` |

The archives remain unsigned. Verify the selected file with `SHA256SUMS`, or
build the exact tag with the pinned toolchain:

```sh
git clone --branch v2.3.0 --depth 1 \
  https://github.com/ResearchPocket/researchpocket.github.io.git
cd researchpocket.github.io
cargo build --locked --release
```
