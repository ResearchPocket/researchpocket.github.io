# ResearchPocket 2.4.0

ResearchPocket 2.4.0 brings Homebrew installation, enriches browser captures
by default, adds bring-your-own-key assistance and Firecrawl page capture to
the browser app, links Zen documents to each other, and makes a save's excerpt
the one text you edit.

## Install

On macOS, with Homebrew:

```sh
brew install korigamik/tap/researchpocket
```

With Rust installed:

```sh
cargo install --locked --force research
```

Or download the verified archive for Linux, macOS, or Windows from the GitHub
release and check it against `SHA256SUMS`.

## What changed

### Native CLI

- **Homebrew.** `brew install korigamik/tap/researchpocket` installs the release
  binary on macOS, and each stable release updates the formula automatically.
- **Browser captures are enriched by default.** Configuring a provider now turns
  on capture enrichment, and `research enrich configure` keeps every setting it
  is not given, so rotating a key no longer switches it off. Toggle it with
  `--on-capture` / `--no-on-capture`, without naming the provider.
- **The capture handler survives upgrades.** On macOS the handler saves through
  the executable bound at installation, and a Homebrew install binds the
  formula's version-independent link, so `brew upgrade` needs no reinstall.
- **`research capture bookmarklet`** prints the bookmarklet, so
  `research capture bookmarklet | pbcopy` copies it on macOS.
- **Chrome and other browsers** are documented for capture: the handler is
  registered with the operating system, not with one browser.

### Browser app

- **Bring-your-own-key assistant.** Connect OpenAI, Anthropic, Gemini,
  OpenRouter, Groq, Mistral, DeepSeek, xAI, Together AI, or a local server such
  as Ollama, and ask it to suggest tags, summarize, or suggest a title for a
  save, or to help write in Zen. Every request names what it sends, and nothing
  changes until you accept it. ADR 0015 records the policy.
- **Firecrawl page capture.** Add a Firecrawl key under
  **Settings → Assistant → Page capture** to capture a save's whole page, or
  every new save automatically. Captured pages sync to your other devices.
  ADR 0016 records the decision.
- **The excerpt is the save's text.** The Reader shows a save's excerpt, or its
  captured original page while it has no excerpt. The edit button turns the
  Reader into an editor for the title, tags, excerpt, and note; trimming a
  captured page saves your copy as the excerpt and keeps the original.
- **Zen links and backlinks.** `[[` completion and an **Insert link** picker
  link documents to each other and to saves, and **Linked from** shows which
  documents refer to the one you are reading. ADR 0014 records the format.
- **Keyboard and reading.** Sidebar shortcuts with on-screen hints, a
  shortcuts dialog on `?`, and notes rendered as Markdown.
- **Phones and appearance.** The installed app fits the iPhone screen without
  zooming or sideways scrolling, a **Font** setting accepts any installed font,
  and dialogs use consistent icons with shorter copy throughout.
- **A rendering error no longer leaves a blank screen.** It shows a message with
  **Reload** instead.

### Security

- Rust dependencies were updated to clear four RustSec advisories, including
  rustls-webpki and its root certificates.

This release does not change the synchronization protocol, SQLite schema,
operation-pack format, checkpoint format, aggregate generation, or repository
layout. Existing native and hosted clients remain wire-compatible. A capture
handler installed by 2.3.0 or earlier keeps saving through its own copy of that
release until you run `research capture install` once.

## GitHub release archives

| Platform | Release asset |
| --- | --- |
| Linux GNU/glibc x86-64 (glibc 2.35 or newer) | `research-v2.4.0-linux-amd64.tar.gz` |
| Windows x86-64 | `research-v2.4.0-windows-amd64.zip` |
| macOS Intel | `research-v2.4.0-macos-amd64.tar.gz` |
| macOS Apple Silicon | `research-v2.4.0-macos-arm64.tar.gz` |

The archives remain unsigned. Verify the selected file with `SHA256SUMS`, or
build the exact tag with the pinned toolchain:

```sh
git clone --branch v2.4.0 --depth 1 \
  https://github.com/ResearchPocket/researchpocket.github.io.git
cd researchpocket.github.io
cargo build --locked --release
```
